Introduction

This notebook builds a Species Distribution Model (SDM) for Bradypus variegatus (three-toed sloth) using a Generalised Linear Model (GLM). Following the standard protocol by Zurell et al. (2020), we use climate data from WorldClim to predict habitat suitability across South America.

Objectives

  1. Load and explore species occurrence data
  2. Generate pseudo-absence points
  3. Extract environmental predictors
  4. Check multicollinearity using VIF
  5. Fit and evaluate a logistic GLM
  6. Map predicted habitat suitability

Species

Bradypus variegatus (three-toed sloth) is a tropical mammal native to Central and South America. It thrives in warm, humid environments and is strongly associated with tropical forest biomes.

# Define colour palette
pal <- colorNumeric(
  palette = c("white", "yellow", "orange", "red"),
  domain = values(prediction_map),
  na.color = "transparent"
)

# Create interactive map
leaflet() %>%
  addProviderTiles(providers$Esri.WorldImagery) %>%
  addRasterImage(prediction_map, 
                 colors = pal, 
                 opacity = 0.7,
                 project = TRUE) %>%
  addLegend(pal = pal,
            values = values(prediction_map),
            title = "Habitat suitability",
